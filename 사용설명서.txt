1부. 앱 기본 사용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ 개요 ]
Gospel Bracelet Cinema는 복음팔찌의 8개 챕터를 시네마틱
파티클 애니메이션으로 발표하는 도구입니다.
발표 화면(프로젝터/노트북)과 스마트폰 리모컨을
Firebase를 통해 실시간으로 동기화합니다.

접속 주소: https://sioninzion.github.io/jayangmonglang/
           (또는 로컬에서 gospel_bracelet_presentation.html 직접 열기)


────────────────────────────────────────────────
1-1. 홈 화면
────────────────────────────────────────────────
앱을 열면 두 버튼이 나타납니다.

  [Presentation]  → 발표 화면 (프로젝터·메인 화면용)
  [Remote]        → 리모컨 화면 (스마트폰·보조 기기용)


────────────────────────────────────────────────
1-2. 발표 화면 시작하기
────────────────────────────────────────────────
1. [Presentation] 클릭
2. 4자리 코드 입력 (0000~9999 중 자유롭게 설정)
3. [시작] 클릭
4. 발표 화면이 열리면 우측 하단에 QR코드와 코드번호 표시됨

   ※ 같은 코드를 북마크해두면 다음번에 바로 진입 가능
      (URL이 ?mode=presentation&room=XXXX 형태로 자동 변경됨)

[ 발표 화면 내 버튼 — 좌측 상단 ]
  ↩   홈으로 돌아가기
  ▶   전체화면(몰입 모드) 진입
  ♬   배경음악 켜기/끄기

[ 키보드 단축키 ]
  →  /  Space  /  PageDown   다음 챕터
  ←  /  PageUp               이전 챕터
  B                           블랙아웃 (화면 완전 암전 토글)
  F                           전체화면 토글
  M                           배경음악 토글
  Esc                         전체화면 해제


────────────────────────────────────────────────
1-3. 리모컨 화면 시작하기
────────────────────────────────────────────────
방법 1 — QR코드 스캔
  발표 화면에 표시된 QR코드를 스마트폰으로 스캔
  → 자동으로 리모컨 화면에 연결됨

방법 2 — 코드 직접 입력
  1. [Remote] 클릭
  2. 하단 "4자리 코드로 연결" 입력창에 발표 화면과 같은 코드 입력
  3. [Connect] 클릭

연결되면 상단에 초록 점(●)과 "Connected" 표시가 나타납니다.

[ 리모컨 버튼 ]
  ◀           이전 챕터
  ▶           다음 챕터
  ♬           배경음악 켜기/끄기
  40%         음량을 현재의 40%로 줄이기 (나눔 중 말할 때)
  ⊙           복음팔찌 구슬 갤러리 보기 (5색 구체 한눈에 확인)
  ↩           홈으로 돌아가기

음량 슬라이더(♬ ──── %)로 배경음악 볼륨 세밀 조절 가능


────────────────────────────────────────────────
1-4. 챕터 내용 (총 8챕터)
────────────────────────────────────────────────
  챕터 1   기본 대기 화면            흰색 구체, 별이 빛나는 우주
  챕터 2   시작                          구체가 폭발하며 흩어짐
  챕터 3   노랑 - 천국                 노랑으로 시작
  챕터 4   검정 - 죄                    노랑 -> 검정
  챕터 5   빨강 - 예수님의 피       검정 -> 빨강
  챕터 6   흰색1 - 용서                붉음 → 흰빛으로 변화, 위로 상승
  챕터 7   흰색2 - 그 다음?          흰 구체, 맨 흙 언덕 위
  챕터 8   초록 - 성장                 흰 구체 → 초록빛, 꽃과 새싹


────────────────────────────────────────────────
1-5. 여러 기기 동시 연결
────────────────────────────────────────────────
  - 같은 코드를 쓰는 모든 기기가 동일 "방"에 연결됨
  - 스마트폰 여러 대를 리모컨으로 동시에 사용 가능
  - 발표 화면 여러 대도 같은 코드로 동기화 가능


────────────────────────────────────────────────
1-6. 배경음악
────────────────────────────────────────────────
  - 음악 파일: Pray - David Tolk.mp3
    (HTML 파일과 같은 폴더 또는 audio/ 하위 폴더에 위치해야 함)
  - 음악을 켜면 Firebase 서버 시간 기준으로 동기화되어 재생
  - 배경음악은 발표 화면 기기에서만 재생됨
    (리모컨 기기에서는 볼륨·토글 제어만 가능)

2부. GitHub Pages 배포 방법 (처음 하는 분용)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GitHub Pages는 무료로 웹사이트를 호스팅해주는 서비스입니다.
계정만 만들면 누구나 무료로 이 앱을 인터넷에 올릴 수 있습니다.
Git이나 코딩 지식 없이도 가능합니다.

배포 후 접속 주소 형태:
  https://내계정이름.github.io/gospel-bracelet/
  (내계정이름 부분은 내가 만든 GitHub 아이디로 바뀜)


────────────────────────────────────────────────
2-1. GitHub 계정 만들기 (이미 있으면 건너뜀)
────────────────────────────────────────────────
1. https://github.com 접속
2. 우측 상단 [Sign up] 클릭
3. 이메일, 비밀번호, 사용자이름(영문) 입력 후 가입
   ※ 사용자이름은 나중에 URL 주소가 되므로
      영문+숫자 조합으로 간단하게 만드는 것을 권장


────────────────────────────────────────────────
2-2. 새 저장소(Repository) 만들기
────────────────────────────────────────────────
1. GitHub에 로그인 후 우측 상단 [+] → [New repository] 클릭
2. 아래와 같이 입력:
     Repository name: gospel-bracelet   ← 원하는 이름 (영문)
     설명(Description): 복음팔찌 앱    ← 선택 사항
     Public 선택 (반드시 Public이어야 무료 배포 가능)
3. [Create repository] 클릭


────────────────────────────────────────────────
2-3. 파일 업로드하기
────────────────────────────────────────────────
1. 방금 만든 저장소 페이지에서
   [uploading an existing file] 링크 클릭
   (또는 [Add file] → [Upload files] 클릭)

2. 아래 파일들을 끌어다 놓거나 선택:
     gospel_bracelet_presentation.html   ← 반드시 포함
     Pray - David Tolk.mp3              ← 배경음악 (선택)

3. 하단 Commit changes 섹션에서
   [Commit changes] 버튼 클릭

   ※ 파일 크기가 25MB를 넘으면 웹 업로드가 안 됩니다.
      mp3 파일이 크다면 GitHub Desktop을 이용하세요. (2-5 참고)


────────────────────────────────────────────────
2-4. GitHub Pages 활성화하기
────────────────────────────────────────────────
1. 저장소 페이지 상단 탭에서 [Settings] 클릭
2. 왼쪽 메뉴에서 [Pages] 클릭
3. Source 항목에서:
     Branch: main 선택
     폴더: / (root) 선택
4. [Save] 클릭
5. 잠시 기다리면 상단에 초록색으로 접속 주소가 나타남:
   "Your site is live at https://내계정.github.io/gospel-bracelet/"

6. 그 주소로 접속하면 앱이 열림!
   전체 URL 예시:
   https://내계정.github.io/gospel-bracelet/gospel_bracelet_presentation.html


────────────────────────────────────────────────
2-5. GitHub Desktop으로 업로드하는 방법 (mp3 등 큰 파일)
────────────────────────────────────────────────
파일 크기가 크거나 웹 업로드가 불편하다면:

1. GitHub Desktop 설치: https://desktop.github.com/
2. GitHub 계정으로 로그인
3. [Clone a repository] → 내 gospel-bracelet 저장소 선택
   → 저장할 폴더 선택 → [Clone]
4. 탐색기에서 클론된 폴더를 열고
   HTML 파일과 mp3 파일을 그 폴더에 복사
5. GitHub Desktop으로 돌아오면 변경된 파일 목록이 보임
6. 좌측 하단 Summary 칸에 간단히 입력 (예: "앱 파일 추가")
7. [Commit to main] 클릭
8. 상단 [Push origin] 클릭
9. 1~2분 후 배포 주소에서 확인


────────────────────────────────────────────────
2-6. 파일 업데이트 (수정 후 다시 배포)
────────────────────────────────────────────────
수정된 HTML 파일을 새로 올리려면:

  방법 A — 웹에서 직접 교체
    1. GitHub 저장소 페이지 접속
    2. 기존 HTML 파일 클릭 → 우측 상단 연필(✏) 아이콘 클릭
    3. ... 어렵다면 아래 방법 B 사용

  방법 B — 파일 다시 업로드
    1. 저장소 페이지에서 [Add file] → [Upload files]
    2. 수정된 파일을 업로드
    3. 같은 파일명이면 덮어쓰기됨
    4. [Commit changes] 클릭
    5. 1~2분 후 반영됨

  방법 C — GitHub Desktop 사용
    1. 저장소 폴더에 수정된 파일을 덮어쓰기
    2. GitHub Desktop에서 변경사항 확인
    3. Commit → Push origin


────────────────────────────────────────────────
2-7. 배포 주소와 QR코드 관계
────────────────────────────────────────────────
리모컨 QR코드는 현재 접속한 URL을 기반으로 자동 생성됩니다.
반드시 GitHub Pages 주소(https://...)로 접속한 상태에서
발표 화면을 시작해야 QR코드가 올바르게 동작합니다.

로컬 파일(file://...)로 열면 QR코드 URL도 file://로 생성되어
다른 사람의 스마트폰에서 접속이 불가능합니다.

3부. 앱 수정 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

앱은 단일 HTML 파일 (gospel_bracelet_presentation.html) 하나로
구성되어 있습니다. 메모장이나 VS Code로 열어 수정합니다.


────────────────────────────────────────────────
3-1. 챕터 제목 바꾸기
────────────────────────────────────────────────
파일에서 아래 부분을 찾아 수정:

  const CHAPTER_INFO=[
    ['기본 대기 화면'],
    ['시작'],
    ['노랑 - 천국'],
    ['검정 - 죄'],
    ['빨강 - 예수님의 피'],
    ['흰색1 - 용서'],
    ['흰색2 - 그 다음?'],
    ['초록 - 성장'],
  ];

각 항목의 텍스트를 원하는 이름으로 변경하면
발표 화면 하단 레이블에 반영됩니다.


────────────────────────────────────────────────
3-2. 챕터 수 변경
────────────────────────────────────────────────
  const TOTAL=8;   ← 이 숫자를 원하는 챕터 수로 변경

단, 챕터 수를 바꾸면 각 챕터의 애니메이션 로직도
함께 수정해야 하므로 주의가 필요합니다.


────────────────────────────────────────────────
3-3. 배경음악 파일 바꾸기
────────────────────────────────────────────────
HTML에서 아래 부분을 찾아 src 경로를 변경:

  <audio class="bgm" id="bgmAudio"
    src="audio/Pray - David Tolk.mp3" ...>

예시: src="audio/새음악파일.mp3"

바꾼 음악 파일도 저장소에 함께 업로드해야 합니다.


────────────────────────────────────────────────
3-4. 홈 화면 설명 텍스트 바꾸기
────────────────────────────────────────────────
HTML에서 아래 부분을 찾아 수정:

  <p class="copy">An interactive cinematic presentation ...</p>

원하는 소개 문구로 변경하면 홈 화면에 반영됩니다.


────────────────────────────────────────────────
3-5. 버전 관리 팁
────────────────────────────────────────────────
  - 수정할 때마다 파일명의 버전 번호를 올리는 것을 권장
    예: v6_16.html → v6_17.html
  - 이전 버전 파일을 삭제하지 않으면 GitHub에 이전 버전도
    남아 있어 롤백이 쉬워집니다.
  - 큰 수정 전에는 파일을 별도로 백업해 두세요.

4부. Firebase 사용법 및 관리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Firebase는 발표 화면과 리모컨 사이의 실시간 동기화를
담당합니다. 현재 프로젝트 이름은 "mongpj1"입니다.


────────────────────────────────────────────────
4-1. Firebase 콘솔 접속
────────────────────────────────────────────────
주소: https://console.firebase.google.com/
→ 프로젝트 "mongpj1" 선택


────────────────────────────────────────────────
4-2. Realtime Database 구조
────────────────────────────────────────────────
데이터 경로: rooms/{4자리코드}/

각 방의 데이터 구조:
  {
    "scene": 1,              현재 챕터 번호 (1~8)
    "blackScreen": false,    블랙아웃 여부
    "gallery": false,        구슬 갤러리 표시 여부
    "music": false,          배경음악 재생 여부
    "musicVolume": 0.72,     음량 (0.0~1.0)
    "musicStartAt": 0,       음악 시작 서버 타임스탬프
    "updatedAt": 타임스탬프, 마지막 업데이트 시각
    "lastParticle": {        마지막으로 추가된 파티클
      "color": "#f7c85f",
      "at": 타임스탬프
    }
  }


────────────────────────────────────────────────
4-3. Firebase 콘솔에서 직접 데이터 수정하기
────────────────────────────────────────────────
Firebase 콘솔 → Realtime Database → 데이터 탭

  rooms/
    0000/        (4자리 코드가 방 ID)
      scene: 3   (← 클릭하면 직접 수정 가능)
      ...

특정 방의 scene 값을 바꾸면 해당 방의 발표 화면이
즉시 해당 챕터로 이동합니다.


────────────────────────────────────────────────
4-4. 오래된 방 데이터 삭제하기
────────────────────────────────────────────────
Firebase 콘솔 → Realtime Database → 데이터 탭

불필요한 방 ID 위에 마우스를 올리면 X 버튼이 나타납니다.
클릭하면 해당 방 데이터가 삭제됩니다.

※ 발표가 끝나면 해당 방 데이터를 삭제해 두는 것이 좋습니다.


────────────────────────────────────────────────
4-5. Firebase 보안 규칙
────────────────────────────────────────────────
현재 앱은 인증 없이 읽기/쓰기가 가능한 구조입니다.
Firebase 콘솔 → Realtime Database → 규칙 탭에서
아래와 같이 설정되어 있어야 앱이 동작합니다:

  {
    "rules": {
      ".read": true,
      ".write": true
    }
  }

보안을 강화하려면 규칙을 수정하거나 Firebase Authentication을
추가해야 하지만, 현재 용도(소규모 발표)에서는 이 설정으로 충분합니다.


────────────────────────────────────────────────
4-6. Firebase 무료 한도
────────────────────────────────────────────────
Realtime Database 무료 플랜 (Spark):
  - 동시 접속: 100개
  - 저장 용량: 1 GB
  - 다운로드: 10 GB/월

복음팔찌 발표 용도에서는 무료 한도를 초과할 가능성이
거의 없습니다.


────────────────────────────────────────────────
4-7. Firebase 설정값 (코드 내 위치)
────────────────────────────────────────────────

5부. 자주 묻는 문제
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q. 리모컨이 연결되지 않아요.
A. 발표 화면과 리모컨의 4자리 코드가 동일한지 확인하세요.
   인터넷 연결 상태도 확인하세요.

Q. QR코드를 스캔했는데 엉뚱한 주소로 연결돼요.
A. 로컬 파일(file://)로 열었기 때문입니다.
   GitHub Pages 주소(https://...)로 접속해서 사용하세요.

Q. 배경음악이 자동으로 재생되지 않아요.
A. 브라우저 정책상 사용자 상호작용 없이는 자동 재생이 차단됩니다.
   발표 화면에서 ♬ 버튼을 한 번 클릭하거나,
   리모컨에서 ♬ 버튼을 눌러 음악을 시작하세요.

Q. 음악 파일이 재생되지 않아요.
A. mp3 파일이 HTML 파일과 같은 폴더(또는 audio/ 폴더)에
   있는지 확인하세요. GitHub에도 mp3 파일이 업로드되어야 합니다.

Q. 발표 중에 화면을 잠깐 끄고 싶어요.
A. 키보드 B 키를 누르거나 리모컨은 없지만 발표 화면에서
   B 키로 블랙아웃을 토글할 수 있습니다.

Q. 발표 화면이 여러 대인데 모두 같이 움직이게 하려면?
A. 모든 발표 화면을 같은 4자리 코드로 열면 동시에 제어됩니다.
