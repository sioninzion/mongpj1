1부. 개요
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Gospel Bracelet Presentation은 복음팔찌의 8개 챕터를
시네마틱 파티클 애니메이션으로 발표하는 도구입니다.

  - 발표 화면(프로젝터/PC)과 스마트폰 리모컨을
    Firebase를 통해 실시간으로 동기화합니다.
  - 여러 대의 리모컨, 여러 대의 발표 화면을
    같은 4자리 코드로 동시에 연결할 수 있습니다.
  - 인터넷 연결이 필요합니다.

2부. 홈 화면
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [Presentation]  → 발표 화면으로 이동
  [Remote]        → 리모컨 화면으로 이동


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3부. 발표 화면 (Presentation)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

────────────────────────────────────────────────
3-1. 시작하기
────────────────────────────────────────────────
1. [Presentation] 클릭
2. 팝업 창에서 4자리 코드 입력 (0000~9999 중 자유 선택)
   ※ 같은 코드를 쓰는 리모컨이 이 화면을 제어합니다
3. [Start] 클릭
4. 발표 화면이 열리며 챕터 1 (Standby)부터 시작됩니다


────────────────────────────────────────────────
3-2. 발표 화면 버튼
────────────────────────────────────────────────
[ 좌측 상단 ]
  ↩   홈으로 돌아가기
  ♬   배경음악 켜기 / 끄기 (켜지면 노란 빛으로 강조)

[ 우측 상단 ]
  ⛶   전체화면 진입 (클릭하면 UI가 사라지고 몰입 모드)
       전체화면 해제: Esc 키 또는 다시 클릭

[ 우측 하단 ]
  QR코드 패널 — 리모컨이 스캔할 QR코드와 연결 코드 표시
  Chapter 카운터 — 현재 챕터 / 전체 챕터 표시


────────────────────────────────────────────────
3-3. 키보드 단축키 (발표 화면에서만 작동)
────────────────────────────────────────────────
  →  /  Space  /  PageDown   다음 챕터
  ←  /  PageUp               이전 챕터
  B                           블랙아웃 토글 (화면 완전 암전)
  F                           전체화면 토글
  M                           배경음악 켜기/끄기
  Esc                         전체화면 해제


────────────────────────────────────────────────
3-4. 코드 입력 팝업
────────────────────────────────────────────────
  - 0000~9999 사이 4자리 숫자
  - 4칸에 한 자리씩 입력 (자동으로 다음 칸으로 이동)
  - 4자리를 한꺼번에 붙여넣기(Paste)도 가능
  - 리모컨에서 같은 코드를 입력해야 연결됨
  - [Cancel] 취소 / [Start] 시작

4부. 리모컨 화면 (Remote) — 상세 안내
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

────────────────────────────────────────────────
4-1. 리모컨 연결하기
────────────────────────────────────────────────
방법 1 — QR코드 스캔 (권장)
  1. 발표 화면 우측 하단의 QR코드를 스마트폰으로 스캔
  2. 브라우저가 열리면서 리모컨 화면에 자동 연결

방법 2 — 코드 직접 입력
  1. 홈 화면에서 [Remote] 클릭
  2. 맨 위 코드 입력칸에 발표 화면과 같은 4자리 코드 입력
  3. [Connect] 버튼 클릭

연결 성공 시:
  - 코드 입력칸이 사라집니다
  - 상태 카드가 나타납니다 (Page / Bead / Screens)
  - "Connected Code" 영역에 초록 점(●)과 "Connected" 표시


────────────────────────────────────────────────
4-2. 상태 카드 (연결 후 표시)
────────────────────────────────────────────────
연결되면 화면 상단에 3가지 정보가 표시됩니다:

  [ Page ]   현재 챕터 번호 / 전체 챕터 수
             예: 3 / 8

  [ Bead ]   현재 챕터의 구슬 색상을 색깔 원으로 표시
             챕터별 색상:
               1 Standby          — 흰색
               2 Beginning        — 흰색
               3 Yellow — Heaven  — 금색 (노랑)
               4 Black — Sin      — 검정
               5 Red — Blood...   — 빨강
               6 White 1 — Forg.  — 흰색
               7 White 2 — Next?  — 흰색
               8 Green — Growth   — 초록

  [ Screens ] 현재 이 코드에 연결된 발표 화면 수
              (리모컨이 아닌 발표 모드로 열린 기기 수)


────────────────────────────────────────────────
4-3. 연결 정보 카드
────────────────────────────────────────────────
  Connected Code  현재 연결된 4자리 코드 표시
  ● Connected     초록 = 연결됨 / 빨강 = 끊김
  ♬ ────── 72%   배경음악 볼륨 슬라이더
                  슬라이더를 좌우로 드래그해 볼륨 조절


────────────────────────────────────────────────
4-4. 리모컨 버튼 (2×2 배열)
────────────────────────────────────────────────
  ┌─────────────┐  ┌─────────────┐
  │      ◀      │  │      ▶      │
  │   Page Up   │  │  Page Down  │
  └─────────────┘  └─────────────┘
  ┌─────────────┐  ┌─────────────┐
  │      ♬      │  │      ⊙      │
  │ Music On/Off│  │   5 Colors  │
  └─────────────┘  └─────────────┘

  [ ◀ Page Up ]
    이전 챕터로 이동합니다.
    챕터 1에서 누르면 더 이상 이동하지 않습니다.

  [ ▶ Page Down ]
    다음 챕터로 이동합니다.
    챕터 8에서 누르면 더 이상 이동하지 않습니다.

  [ ♬ Music On / Off ]
    배경음악을 켜거나 끕니다.
    켜져 있을 때 버튼이 노랗게 강조됩니다.
    처음 켤 때 서버 시간으로 타임스탬프가 기록되어
    여러 발표 화면의 음악이 동기화됩니다.

  [ ⊙ 5 Colors ]
    복음팔찌 5가지 색상 구체를 한 화면에 보여주는
    갤러리 모드를 켜거나 끕니다.
    (금색·검정·빨강·흰색·초록 구체 한눈에 확인)
    다시 누르면 갤러리가 닫힙니다.


────────────────────────────────────────────────
4-5. 리모컨 사용 팁
────────────────────────────────────────────────
  - 리모컨 기기에서는 배경음악이 재생되지 않습니다.
    음악은 발표 화면에서만 들립니다.
  - 나눔 중 음성 전달이 필요할 때는 볼륨 슬라이더로
    배경음악을 낮추세요.
  - 여러 명이 각자 스마트폰으로 리모컨을 열어
    동시에 사용할 수 있습니다.
  - 연결이 끊어지면 빨간 점이 나타납니다.
    페이지를 새로 고침하거나 다시 코드를 입력하세요.

5부. 챕터 내용 가이드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  챕터 1   Standby
           흰색 구체, 별이 빛나는 우주 배경
           발표 시작 전 대기 화면으로 활용

  챕터 2   Beginning
           구체가 빠르게 회전하다 폭발하며 흩어짐
           (약 6초 애니메이션)

  챕터 3   Yellow — Heaven
           흩어진 파티클이 모여 금빛 구체를 이룸
           천국, 하나님의 완전함을 상징

  챕터 4   Black — Sin
           금빛 구체가 점점 어두워져 검게 변함
           죄로 인한 타락을 묘사

  챕터 5   Red — The Blood of Jesus
           어두운 구체가 붉게 물들며 빗속 골목 배경
           예수님의 보혈을 상징

  챕터 6   White 1 — Forgiveness
           붉은 구체가 흰빛으로 변하며 위로 상승
           죄 용서와 구원을 표현

  챕터 7   White 2 — What's Next?
           흰 구체가 맨 흙 언덕 위에 위치
           신앙 이후의 삶, 씨앗의 이미지

  챕터 8   Green — Growth
           구체가 초록빛으로 변하고 언덕에 꽃과 새싹이 자람
           성령 안의 성장과 새 생명

Q. 리모컨이 연결되지 않아요.
A. 발표 화면과 리모컨의 코드가 같은지 확인하세요.
   인터넷 연결도 확인하세요. 연결 후 빨간 점이 보이면
   페이지를 새로 고침하고 다시 코드를 입력하세요.

Q. QR코드가 작동하지 않아요.
A. 반드시 GitHub Pages 주소(https://)로 접속한 상태에서
   발표를 시작해야 QR코드 URL이 올바르게 생성됩니다.
   로컬 파일(file://)에서 열면 QR코드가 동작하지 않습니다.

Q. 배경음악이 재생되지 않아요.
A. 브라우저 자동재생 차단 정책 때문입니다.
   발표 화면에서 ♬ 버튼을 직접 클릭하거나
   리모컨에서 Music On/Off 버튼을 누르세요.

Q. mp3 파일이 재생되지 않아요.
A. HTML 파일과 mp3 파일이 같은 폴더(또는 audio/)에
   있어야 합니다. GitHub에도 mp3를 업로드했는지 확인하세요.

Q. 화면을 잠깐 끄고 싶어요.
A. 발표 화면에서 B 키를 누르면 블랙아웃(완전 암전)이 됩니다.
   다시 B 키를 누르면 복구됩니다.

Q. 발표 화면이 여러 대인데 모두 같이 제어하려면?
A. 모든 발표 화면을 같은 4자리 코드로 열면 됩니다.
   리모컨의 Screens 표시로 몇 대가 연결됐는지 확인하세요.

Q. Screens 숫자가 0이에요.
A. Screens는 발표(Presentation) 모드로 열린 기기 수입니다.
   리모컨(Remote) 모드는 카운트되지 않습니다.
